# 心里韧带 Ligament

评估青少年心理韧性的移动端 H5 原型：情绪自查量表、韧性训练打卡、沟通支持对话与真实康复案例，管理端只读聚合统计。

线上地址（本仓库经 GitHub Pages 部署）：<https://mtjvmysnk9-tech.github.io/xinli-ligand-app/>
正式站点（含真实上报）：<https://xinli-ligand-t3tamdheczu.qoder.zone/>

- 产品定义：目标用户（有情绪困扰但不知道如何开口的青少年）、核心任务（30 秒完成一次自查）、五个模块的信息架构与跳转逻辑。
- 量表口径设计：采用国际韧性量表简化版；统计以「人·日」为单位而不是以记录条数为单位，避免记录多的人被放大。
- 案例内容：真实康复长文 + 可播放视频，来源可追溯；食物糖量清单 22 项按红绿灯分级。
- 后台呈现范围决策：管理端只读进入记录（谁、什么时候、什么方式），情绪记录和对话内容不上传，降低隐私面。
- 代码由 AI 辅助生成，我负责需求拆解、口径定义、逐条验收与线上验证。

## 结构

| 文件 | 作用 |
| --- | --- |
| `index.html` | 访客端单页应用，记录保存在浏览器 `localStorage` |
| `admin.html` | 管理端仪表盘，读取服务端聚合接口，含 CSV 导出 |
| `functions/` | 后端 Edge Function（认证、会话、限流、导出） |
| `miniprogram/` | 微信小程序版本（原生框架） |
| `dev/serve.mjs` | 本地演练服务器（Deno） |

无构建步骤、无依赖包，纯静态。

## 两处部署的差别

后端接口跑在另一台主机上，网关对写操作校验 `Origin`，只接受来自正式站点自身的请求。因此同一份代码在 GitHub Pages 上会自动降级：

| | 正式站点 | 本仓库（GitHub Pages） |
| --- | --- | --- |
| 注册与记录 | 本机保存 + 匿名上报 | 仅本机保存，「本地演示模式」 |
| 管理端聚合数据 | 可读 | 可读（读接口 CORS 开放） |

## 数据说明

- 情绪自查结果仅存本机，不上传服务端。
- 管理端只记录「谁在什么时候用什么方式进入」，不记录具体内容。
- 正式站点上有用于演示的批量样例记录，与管理端看到的早期数字来自同一批数据。

## 本地运行

```
deno run --allow-net --allow-env --allow-read dev/serve.mjs
```

或直接双击 `index.html`（`localStorage` 在 `file://` 下同样可用）。
